# Changelog

## [1.0.0-rc.1] - 2026-10-23

First release candidate.

- Discovery: smart home feed, search with filters, Explore map with nearby
  events, favorites.
- Booking: tier picker with live stock, 10-minute holds, mock checkout,
  rotating signed QR tickets that work offline, refunds (full refund more
  than 48 hours before the start, none after), reminders, add to calendar.
- Reviews from ticket holders; event cards, details and the map sheet show
  the live review average and live stock ("Only N left", "Sold out").
- Organizer mode: dashboard, create/edit wizard, QR check-in with an offline
  sync queue.
- English, French and Arabic (RTL), light and dark themes.
- Accessibility: labelled icon buttons, photos, QR and chart; 48 dp tap
  targets; layouts hold at 1.3x text size.
- CI/CD: format, analyze, l10n and coverage gates; Android release (AAB/APK),
  unsigned iOS build, tag-driven GitHub Releases; Fastlane skeleton.
